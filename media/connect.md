# Connect to Unleash

Use your instance URL and a Personal Access Token from **Profile → Personal API tokens**.

All projects your token can read are included automatically. Credentials are stored in VS Code SecretStorage, never in settings or source files.

After connecting, open a file that contains a flag name and hover the string. You will see the current rollout, targeting and release milestone.

You can also start with the offline demo.
